# Scene Loom product brief

## Purpose and audience

A personal local studio for seeing, understanding, and evolving game storyboards maintained by AI agents from Codex chats. The owner prompts the agent externally, then reviews the results visually. Scene Loom itself does not need an AI service or API key.

## Agreed workflow

1. Open a game project: it has one zoomable canvas for the entire game.
2. In Codex, discuss ideas and request complete scene material, including images.
3. The agent imports images and submits structured scene and connection updates.
4. Scene Loom displays the successful update automatically without manual importing or reloading.
5. Pan, zoom, fit the canvas, drag cards, and open scene details. Positions persist.
6. Copy a card's Continue from here or Edit this scene prompt, paste into Codex, and add direction.
7. The agent reads current state and revises the existing scene or adds connected scenes. Revisions replace the current idea; no visible alternate-version workflow.

## Content and interaction

- Each card represents a flexible scene or gameplay moment, not necessarily a cinematic shot.
- Every published card has a main image. Optional supporting images appear in its details.
- Card details contain a description and notes; meaningful titles remain visible on the canvas.
- Arrows support branches, joins, loops, and optional short labels.
- Users can move cards. Agents preserve their arrangement unless explicitly asked to reorganize it.
- Copy buttons carry stable project/scene references and instructions to read current content, not stale copies of all notes. Nothing is automatically sent to a chat.

## Approved design and tools

After Hours: graphite, off-white, and pale blue with expressive display typography; creative studio character; animated card opening and interactions. React Flow and Motion approved. Impeccable approved and installed in the owner's Codex skills directory. No reduced-motion support work requested.

## First-version additions

Search/focus a scene, fit all, subtle recent-update feedback, and local recovery snapshots. Included through approval of the implementation plan on 2026-11-05.

## Exclusions

Built-in chat or image generation, game engine integration, 3D asset studio, multiplayer, cloud accounts/sync, hosting, mobile-first interface, nested boards, alternate idea comparison, manual scene-content authoring UI, general drawing/whiteboard tools, automatic global rearrangement, and media timelines.
